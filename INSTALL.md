# Сборка и установка

Инструкция для локальной сборки расширения Smart Commit Message и установки его в VS Code.

## Требования

- [Node.js и npm](https://nodejs.org/)
- VS Code версии 1.85 или новее

## Сборка `.vsix`

Откройте терминал в корневой папке проекта.

Установите зависимости проекта (обычно только при первой сборке или после изменения зависимостей):

```bash
npm install
```

Скомпилируйте расширение:

```bash
npm run compile
```

Установите упаковщик VS Code Extensions:

```bash
npm install -g @vscode/vsce
```

Создайте устанавливаемый пакет:

```bash
vsce package
```

В корневой папке проекта появится файл с расширением `.vsix`, например:

```text
smart-commit-message-0.1.0.vsix
```

### Если не устанавливается `vsce`

Запустите его через `npx`, используя отдельную временную папку для npm-кэша:

```bash
npm_config_cache="$TMPDIR/npm-cache" npx --yes @vscode/vsce package
```

## Установка в VS Code

1. Откройте VS Code и перейдите в **Extensions**.
2. Нажмите `…` в меню расширений.
3. Выберите **Install from VSIX…**.
4. Укажите собранный `.vsix`-файл.
5. Перезапустите VS Code, если появится предложение.

## Повторная сборка после изменений

Если зависимости не менялись, повторно выполнять `npm install` не нужно:

```bash
npm run compile
vsce package
```

Установите новый `.vsix` тем же способом. Если глобальная команда `vsce` недоступна, используйте команду с `npx` выше.

## Запуск для разработки

Вместо упаковки можно открыть папку проекта в VS Code и нажать `F5`. Откроется Extension Development Host с запущенным расширением. Для этого предварительно выполните `npm install` и `npm run compile`.
