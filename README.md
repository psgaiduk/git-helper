# Smart Commit Message

Расширение для VS Code, которое генерирует сообщение коммита по staged changes и текущей Git-ветке.

Для ветки `dwh-123-do-something` сообщение будет начинаться с `#DWH-123`:

```text
#DWH-123 feat: add customer dimension
```

Расширение заполняет поле сообщения в Source Control, а тег релиза создаёт только после явного нажатия кнопки.

## Как работает

1. Добавьте нужные файлы в **Staged Changes**.
2. Откройте раздел **Smart Commit** на боковой панели и нажмите **Generate commit message**. Также можно нажать sparkle-кнопку в заголовке Source Control.
3. Расширение отправит staged diff выбранной модели и подставит ответ в поле сообщения коммита.

На боковой панели доступны вкладки **Настройки** и **Работа**. Во вкладке «Работа» также можно подготовить тег релиза: расширение берёт коммиты, достижимые из текущего `HEAD`, после ближайшего предыдущего тега (включая коммиты влитых веток), либо всю достижимую историю, если тегов ещё нет. Описание группируется по ID задач в названиях веток и сообщениях коммитов: `M-1: Сделано ...`; каждая строка ограничена 150 символами. Описание можно отредактировать перед созданием. После нажатия **Создать аннотированный тег** тег создаётся на текущем `HEAD`. Тег создаётся локально; для отправки в удалённый репозиторий используйте `git push --tags`.

Префикс берётся из первых двух частей имени ветки. Например, `dwh-123-anything` превращается в `#DWH-123`. Модель выбирает тип коммита:

| Тип | Назначение |
| --- | --- |
| `feat` | Новая возможность |
| `fix` | Исправление ошибки |
| `refactoring` | Изменение структуры без изменения поведения |
| `style` | Форматирование и исправления линтера |
| `devops` | Инфраструктура и развёртывание |
| `docs` | Документация |
| `test` | Только тесты |

## Настройки модели и API

Настройки можно задать в разделе **Smart Commit** на боковой панели или открыть настройки VS Code (`⌘,` на macOS или `Ctrl+,` на Windows/Linux) и найти **Smart Commit Message**. Можно задать:

- `smartCommit.apiUrl` — базовый URL OpenAI-совместимого API. Расширение добавляет `/chat/completions`.
- `smartCommit.model` — имя модели, которое принимает этот API. По умолчанию `gpt-4o-mini`.

Например, конфигурация в `settings.json` может выглядеть так:

```json
{
  "smartCommit.apiUrl": "https://api.openai.com/v1",
  "smartCommit.model": "gpt-4o-mini"
}
```

Это пример: порт, путь API и имя модели зависят от программы, через которую запущена модель. Сервер должен поддерживать `POST /chat/completions`.

### API-токен

Токен необязателен. Если он сохранён, расширение добавляет заголовок `Authorization: Bearer …`. Для локального сервера без авторизации удалите сохранённый токен командой ниже и оставьте поле пустым.

Чтобы добавить или заменить токен, откройте палитру команд (`⌘⇧P` на macOS или `Ctrl+Shift+P` на Windows/Linux) и выполните:

```text
   Smart Commit Message: Set API Token
```

Введите токен, если ваш сервер его требует. Чтобы удалить сохранённый токен и отправлять запросы без него, запустите команду ещё раз и оставьте поле пустым. Токен хранится в защищённом хранилище VS Code, а не в `settings.json`.

> Подписка ChatGPT Plus не включает API. Использование OpenAI API оплачивается отдельно.
